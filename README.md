Task 9 – Brazilian E-Commerce Cohort Analysis
📌 Project Overview
This project analyzes customer retention and purchasing behavior using the Brazilian E-Commerce dataset.
The analysis focuses on cohort analysis to understand how customer retention changes over time and to identify key business insights.
🛠️ Tools & Technologies
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
📊 Analysis Performed
* Data cleaning and preprocessing
* Customer purchase analysis
* Cohort creation
* Retention rate calculation
* Cohort retention heatmap
* Identification of customer retention patterns
* Business insights and conclusions
💡 Key Insights
The cohort analysis helps identify how customer retention changes across different customer acquisition cohorts and highlights patterns in repeat purchasing behavior.
 📁 Project Files
* `Task 9.ipynb` – Main analysis notebook
* Dataset files – Data used for the analysis
* Screenshots – Selected analysis results and visualizations
 🎯 Objective
The main objective is to use cohort analysis to evaluate customer retention and provide meaningful business insights from e-commerce transaction data.
